Peringatan Keamanan Browser (CORS file:// Protocol)

Aplikasi web modern berbasis ES Modules, Service Worker, dan PWA Manifest diblokir oleh kebijakan keamanan browser jika dibuka langsung melalui double-click berkas (protokol file://).

Jalankan web server lokal melalui terminal:
python3 -m http.server 8080
Lalu buka di browser: http://localhost:8080
